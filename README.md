## Juego de tenis

Aplicación gráfica de un juego de tenis desarrollada en C++ utilizando OpenGL y GLUT.

## Práctica 2

Se ha añadido un proceso logger que se comunica con el juego por medio de una tuberia con nombre (FIFO)
Este proceso informa cada vez que uno de los jugadores anota un punto, y muestra su puntuación total
Se alcanza el final del juego cuando uno de los jugadores llega a 3 puntos
